# Opus Atlas · 클래식 음악 학습 아카이브

시대, 작곡가, 장르·형식, 음악 이론, 작품 번호(Op., K., D., BWV …), 명연주를 하나의 연결된 지식 지도로 배우는 클래식 입문 사이트입니다. 빌드 도구 없이 정적 파일만으로 동작합니다.

## 실행

```bash
cd classical && python3 -m http.server 8000
```

브라우저에서 http://localhost:8000 을 엽니다. GitHub Pages 등 정적 호스팅에 `classical/` 폴더를 그대로 올려도 됩니다.

## 구성

| 메뉴 | 내용 |
|---|---|
| 구조 | 다섯 개의 층, 작품별 관계 지도, 네 가지 분류 축 |
| 이론 | 12개 항목 (장·단조, 조성, 음계, 음정, 화성, 선율, 리듬, 박자, 템포, 셈여림, 악장, 악보 읽기) — 건반·메트로놈 소리 예시 |
| 장르·형식 | 22개 장르 — 정의, 특징, 역사, 심화, 감상 팁, 대표 작품 |
| 시대 | 중세 ~ 20세기·현대 7개 시대, 작곡가 연대표 |
| 작곡가 | 13명 — 생애, 특징, 작품 번호 체계, 추천 감상 순서, 대표 음반, 필터 |
| 작품 | 71곡 — 공통 템플릿(조성, 편성, 악장, 번호 해설, 배경, 감상 포인트, 명반, 메모) |
| 작품번호 | 해독기(예: `Op. 27 No. 2`, `Hob. I:94`) + 13개 표기 사전 |
| 명반 | 같은 곡의 녹음 비교, 연주자 71명 사전 |
| 용어 | 95개 용어 — 본문 점선 밑줄 툴팁과 연결 |
| 퀴즈 | 데이터에서 자동 생성되는 4개 영역 퀴즈 |
| 내 서재 | 즐겨찾기, 감상 완료, 메모, 학습 진도 (브라우저 localStorage) |

검색은 `/` 또는 `⌘K`. 작품 번호는 띄어쓰기·마침표 없이도 찾습니다(`op9no2`, `k525`).

## Apple Music 연동

- **기본 (설정 불필요):** ‘듣기’를 누르면 iTunes Search API로 Apple Music 카탈로그를 검색하고, 결과를 Apple 공식 임베드 플레이어로 재생합니다. 브라우저에서 Apple Music에 로그인한 구독자는 전체 곡, 그 외에는 미리듣기가 재생됩니다.
- **전체 재생 (선택):** `js/config.js`의 `musicKitDeveloperToken`에 MusicKit 개발자 토큰(Apple Developer 계정의 MusicKit 키로 서명한 JWT)을 넣으면 플레이어에 ‘Apple Music 계정 연결’ 버튼이 생기고, 로그인한 구독자는 페이지 안에서 바로 전체 곡을 재생합니다. 토큰은 공개 저장소에 올리지 말고 배포 시 주입하세요.
- `storefront`(기본 `kr`)로 국가별 카탈로그를 바꿀 수 있습니다.

음원은 저장하거나 업로드하지 않고 Apple의 공식 경로로만 연결합니다.

## 콘텐츠 수정

모든 콘텐츠는 `js/data/*.js`에 있습니다. 본문 안 `[[w:작품id|표시 텍스트]]`처럼 쓰면 자동으로 링크가 됩니다 (`c` 작곡가, `w` 작품, `g` 장르, `e` 시대, `th` 이론, `t` 용어 툴팁, `p` 연주자, `cat` 작품 번호).
