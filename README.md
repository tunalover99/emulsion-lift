# 에멀전 리프트 · Emulsion Lift

즉석사진의 이미지 막(유제층)을 물에서 떼어 종이, 잎, 돌, 나무 위에 옮기는 **에멀전 리프트**를 브라우저에서 실제 순서대로 따라 하는 작업실입니다. 한국어와 영어로 볼 수 있습니다.

- **메인:** 지금까지 만든 리프트가 캡션과 함께 놓입니다. 작업이 없으면 예시가 보입니다.
- **?** 에멀전 리프트 설명. **+** 새 리프트 만들기(인화 → 뜨거운 물 → 찬물에서 떼어내기 → 옮길 곳 고르기 → 모양 잡기 → 말리기). **@** 아카이브(이 브라우저에 보관, 손으로 만든 리프트 사진 추가).
- **표면:** 돌과 벽돌 사진 9장, 찢은 종이·신문·책 낱장·지도 등 종이 사진 15장. 트레이와 예시 사진도 Figma 디자인의 사진을 씁니다. 흰 바탕에서 찍은 물체 사진을 올리면 바탕을 지우고 그 모양대로 옮깁니다.

`index.html`, `surfaces/`(물체·종이·트레이 사진), `photos/`(예시 사진), `examples/`(작업이 없을 때 보이는 예시)로 동작합니다. 글꼴은 영문 Arial(시스템 글꼴), 한글 Pretendard Regular(`fonts/`, SIL OFL 1.1)이며 외부 의존성은 없습니다.

## 어제 뭐 입었지 (`ootd/`)

매일 입은 옷을 기록하는 별도 웹앱입니다. 휴대폰(아이폰 16 기준) 위주로 만들었고, 홈 화면에 추가하면 앱처럼 쓸 수 있습니다(PWA).

- **캘린더:** 빨간 선 달력에 날짜마다 그날의 코디가 보입니다. 날짜를 누르면 코디, 입은 피스 목록, 태그, 메모가 나옵니다. 전날과 겹치는 옷이 있으면 알려 줍니다.
- **태그:** `#알바` 같은 태그를 누르면 그 태그가 달린 날만 남고 "마지막 알바 날"로 바로 갈 수 있습니다.
- **옷 스캔:** 아래 가운데 스캔 버튼 → 카메라로 옷을 찍으면 기기 안에서 AI(U²-Net `u2netp`, Apache-2.0, `ootd/models/`)가 옷만 남기고 배경을 지웁니다. 이름과 종류를 붙여 옷장에 넣거나 투명 PNG로 저장할 수 있습니다. 사진은 서버로 보내지지 않습니다.
- **옷장:** 착용 횟수와 마지막으로 입은 날을 보여 줍니다.
- **코디:** 옷장 피스를 끌어다 놓아 코디를 만들고 날짜에 기록하거나 코디 목록에 저장합니다. 최근 3일 안에 입은 피스에는 표시가 붙습니다.
- 메뉴의 "예시 옷장 채워 보기"는 `ootd/demo/`의 실사 제품 사진(AI로 생성 후 배경 제거) 18장을 씁니다.
- 데이터는 이 브라우저(IndexedDB)에만 저장됩니다. 메뉴의 "백업 파일 내보내기/가져오기"로 기기를 옮길 수 있습니다.
- 외부 의존성: Google Fonts(Bodoni Moda, Geist, Noto Serif KR), Pretendard(jsDelivr), onnxruntime-web 1.20.1(jsDelivr, 스캔할 때만 불러옴).
