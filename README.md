# 에멀전 리프트 · Emulsion Lift

즉석사진의 이미지 막(유제층)을 물에서 떼어 종이, 잎, 돌, 나무 위에 옮기는 **에멀전 리프트**를 브라우저에서 실제 순서대로 따라 하는 작업실입니다. 한국어와 영어로 볼 수 있습니다.

- **작업들:** 만든 리프트가 회색 바탕 위에 돌멩이처럼 놓입니다. 작업은 이 브라우저(IndexedDB)에만 보관되고, 손으로 만든 리프트 사진도 함께 올릴 수 있습니다.
- **새 리프트:** 인화 → 뜨거운 물 → 찬물에서 떼어내기 → 표면에 옮기고 모양 잡기 → 말리기.
- **표면:** 수채화지(콜드·핫프레스), 한지, 크라프트지, 리넨, 무화과 잎, 긴 잎 세 장, 조약돌, 나무판.

`index.html` 한 파일과 `examples/`(작업이 없을 때 보이는 예시)로 동작합니다. 외부 의존성은 Google Fonts(Gowun Batang, Cormorant Garamond)뿐입니다.

---

## 어제 뭐 입었지 (`ootd/`)

매일 입은 옷을 기록하는 별도 웹앱입니다. `ootd/index.html` 한 파일로 동작하고, 휴대폰에서는 홈 화면에 추가해 앱처럼 쓸 수 있습니다(PWA).

- **캘린더:** 빨간 선 달력에 날짜마다 그날의 코디가 보입니다. 날짜를 누르면 코디, 입은 피스 목록, 태그, 메모가 나옵니다. 전날과 겹치는 옷이 있으면 알려 줍니다.
- **태그:** `#알바` 같은 태그를 누르면 그 태그가 달린 날만 남고 "마지막 알바 날"로 바로 갈 수 있습니다.
- **옷장:** 옷 사진을 찍으면 배경을 자동으로 지우고(지우개/되살리기로 다듬기) 피스로 모읍니다. 착용 횟수, 마지막으로 입은 날을 보여 줍니다.
- **코디:** 옷장 피스를 끌어다 놓아 코디를 만들고 날짜에 기록하거나 코디 목록에 저장합니다. 최근 3일 안에 입은 피스에는 표시가 붙습니다.
- 데이터는 이 브라우저(IndexedDB)에만 저장됩니다. 메뉴의 "백업 파일 내보내기/가져오기"로 기기를 옮길 수 있습니다.
