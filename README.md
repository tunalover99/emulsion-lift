# 에멀전 리프트 작업실

즉석사진의 이미지 막(유제층)을 물에서 떼어 다른 종이에 옮기는 **에멀전 리프트**를 브라우저에서 실제 순서대로 따라 하는 시뮬레이터입니다.

1. 필름 고르고 인화하기 (필 어파트 FP-100C / 폴라로이드 인티그럴)
2. 뜨거운 물에 담그기 (온도에 따라 들뜨는 속도, 가장자리 상태가 달라짐)
3. 찬물에서 막 떼어내기
4. 종이에 옮기고 모양 잡기 (밀기, 주름 모으기, 펴기, 찢기, 뒤집기, 담갔다 빼기)
5. 말리고 PNG로 저장

`index.html` 한 파일로 동작합니다 (WebGL, 외부 의존성은 Google Fonts뿐).
