# 에멀전 리프트 · Emulsion Lift

즉석사진의 이미지 막(유제층)을 물에서 떼어 종이, 잎, 돌, 나무 위에 옮기는 **에멀전 리프트**를 브라우저에서 실제 순서대로 따라 하는 작업실입니다. 한국어와 영어로 볼 수 있습니다.

- **메인:** 지금까지 만든 리프트가 캡션과 함께 놓입니다. 작업이 없으면 예시가 보입니다.
- **?** 에멀전 리프트 설명. **+** 새 리프트 만들기(인화 → 뜨거운 물 → 찬물에서 떼어내기 → 옮길 곳 고르기 → 모양 잡기 → 말리기). **@** 아카이브(이 브라우저에 보관, 손으로 만든 리프트 사진 추가).
- **표면:** 돌과 벽돌 사진 9장, 찢은 종이·신문·책 낱장·지도 등 종이 사진 15장. 트레이와 예시 사진도 Figma 디자인의 사진을 씁니다. 흰 바탕에서 찍은 물체 사진을 올리면 바탕을 지우고 그 모양대로 옮깁니다.

`index.html`, `surfaces/`(물체·종이·트레이 사진), `photos/`(예시 사진), `examples/`(작업이 없을 때 보이는 예시)로 동작합니다. 글꼴은 영문 Arial(시스템 글꼴), 한글 Pretendard Regular(`fonts/`, SIL OFL 1.1)이며 외부 의존성은 없습니다.
